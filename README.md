# The GameMaker Source Code for Experience
Requirements to run/build the game
* Latest version of [GameMaker Studio](https://gamemaker.io/en)
* Windows machine preferrably, also prefer using Windows 10-11 to ensure compatibility (Only the PCs with access to Windows, Linux, Mac can run the GameMaker IDE anyways)
* [Microsoft Visual Studio](https://visualstudio.microsoft.com) 18+ for YYC builds
